# Подпись установщика (Windows)

Без подписи Windows SmartScreen пишет «Неизвестный издатель», а многие пользователи
пугаются и не запускают. Подпись убирает неизвестного издателя, но SmartScreen всё
равно может предупреждать, пока у сертификата нет «репутации». У EV-сертификата
репутация есть сразу, у обычного (OV) — набирается со временем и скачиваниями.

## 1. Купить сертификат

Нужен сертификат для подписи кода (Code Signing). Варианты:
- **OV** (обычный) — дешевле, репутация набирается постепенно.
- **EV** (расширенный) — дороже, предупреждения SmartScreen почти сразу не появляются.
- Облачная подпись (например, Azure Trusted Signing) — без файла сертификата, но
  настраивается отдельно: `azureSignOptions` в `package.json`.

## 2. Добавить секреты в GitHub

Репозиторий → Settings → Secrets and variables → Actions → New repository secret:

- `WIN_CSC_LINK` — файл сертификата `.pfx`, закодированный в base64
  (в PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cert.pfx"))`)
- `WIN_CSC_KEY_PASSWORD` — пароль от `.pfx`

Пока секретов нет, сборка идёт без подписи, ничего не ломается.

## 3. Выпуск

Как обычно: тег `vX.Y.Z`. Сборка подпишет установщик и portable-exe автоматически
(electron-builder читает `CSC_LINK` и `CSC_KEY_PASSWORD`, см. `.github/workflows/release.yml`).

Важно: обновления у уже установленных версий проверяют издателя. Если первые версии
были без подписи, переход на подписанные работает; дальше все версии должны быть
подписаны одним и тем же сертификатом.
