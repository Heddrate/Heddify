Скопируй этот текст целиком в новую сессию агента.

Ты продолжаешь разработку Heddify — Windows-приложения (Electron) для прослушивания музыки из SoundCloud, Яндекс Музыки и Audius, а также радио и собственных файлов.

## Владелец и стиль работы
- Владелец — Heddrate. Пишет по-русски, неформально. Отвечай коротко и по-русски, без воды.
- Он хочет, чтобы всё делалось само, «под ключ»: код, тесты, релиз. Спрашивай только то, что реально требует его решения (деньги, аккаунт, выбор функции).
- Если нужны шаги от него — давай 1–3 простых шага, без жаргона.
- «Задеплоил?» значит: собран ли и опубликован ли релиз на GitHub. Проверяй через API, не угадывай.
- Коммиты и релизы делай сам только когда он попросил «заливай/деплой/выпускай». Без просьбы не коммить и не пушь.

## Что нельзя (жёстко)
- Не обходить DRM: не трогать протокол лицензий SoundCloud, не запускать castlabs EVS-подпись, не отлаживать ответы лицензионного сервера. Треки с DRM остаются с кнопкой «открыть в браузере».
- Не решать капчи и антибот-защиту, не вытаскивать client_id из JS SoundCloud.
- Не подписывать запросы и не получать stream-URL Яндекса в обход официальной страницы music.yandex.ru.
- Не извлекать, не читать и не печатать токены, пароли и cookie пользователя. Он вставляет их сам в диалог приложения.
- Не запускать и не перезапускать установленное у владельца приложение (MSIX-виртуализация AppData). Тестируй через `npm run dev:web` и браузерные тесты.
- Не добавлять в коммиты и PR строки `Co-Authored-By: Claude…` или «Generated with Claude Code». Автор коммита: `Heddrate <211876846+Heddrate@users.noreply.github.com>`.
- Не публиковать и не покупать ничего внешнего (сертификаты, подписки) без его явного «да».

## Команды
- Проверка типов (именно эта, root `tsc` ничего не проверяет): `npm run typecheck`
- Модульные тесты: `npm test`
- Браузерные тесты: `npm run test:e2e` (в первый раз `npx playwright install chromium`)
- Превью с моком: `npm run dev:web` (порт 5173)
- Сборка: `npm run build`

Перед любым коммитом: typecheck, `npm test`, `npm run test:e2e` — все зелёные. Если упало — чинить, а не пропускать.

## Как выпустить версию
1. Поднять `version` в `package.json` (строка 4).
2. Написать `release/notes/vX.Y.Z.md` — короткие пункты по-русски, что изменилось для пользователя.
3. `git add -A`, коммит без Co-Authored-By, `git push origin main`.
4. `git tag vX.Y.Z` и `git push origin vX.Y.Z` — это запускает сборку.
5. Проверка: `https://api.github.com/repos/Heddrate/Heddify/actions/runs?per_page=1` (status/conclusion) и `https://api.github.com/repos/Heddrate/Heddify/releases/latest`. Не поллить в цикле — один-два запроса.
- Если сборка упала на шаге тестов или typecheck — исправить, поднять версию (например, 1.8.5), не переписывать опубликованные теги.

## Что уже работает (1.8.4)
- Поиск, библиотека, очередь, полноэкранный плеер (текст по строкам, плавная смена обложки), волна (Моя волна), радио (Radio Browser, курированные станции), свои файлы, плейлисты (можно добавлять треки из любого сервиса).
- Перемешивание: список не переставляется, порядок воспроизведения — в `plan`, история — в `history` (`lib/queueOrder.ts`, покрыто тестами).
- Артисты трека — отдельные ссылки (Яндекс — все артисты с id; SoundCloud — соавторы из поля исполнителя и «feat.» в названии, поиск по точному имени).
- Автообновление: проверка при старте (через 15 с) и каждые 4 часа, скачивание в фоне, точка на аватарке пульсирует, «Обновить» появляется после скачивания. Установка при перезапуске.
- Настройки: карточки-разделы, автопродолжение (выключено по умолчанию, у старых пользователей тоже выключено), плавный переход (выключен), выравнивание громкости, «Что нового».
- Счётчик «Подписки» в боковой панели берётся из живого набора подписок.

## Открыто / известные риски
- **Подпись установщика.** Нужен сертификат, его покупает владелец. Без него SmartScreen показывает «неизвестный издатель». Инструкция: `docs/SIGNING.md`.
- **Яндекс: автозапуск и громкость** исправлены в 1.7.x, но в живом приложении не проверены (нужен аккаунт Яндекса). Скрытая страница не должна стартовать сама; громкость стартует с нуля до установки уровня.
- **Плавный переход и выравнивание громкости** идут через Web Audio. Нужен CORS на потоке: для некоторых потоков звук может не играть. Пока известного случая нет, но он возможен.
- **Автообновление** на собранной установке не проверялось end-to-end (в dev апдейтер отключён, `installed()` требует uninstall-файл рядом с exe). Проверить на установленной версии после выхода новой.
- **DRM-треки SoundCloud** не играют, это тупик (см. выше). Не браться.
- **Spotify** не поддерживается.
- **Иконка приложения**: если Windows показывает старую иконку — это кэш иконок (`ie4uinit.exe -show`), не сборка.
- **Картинка радио по http**: сайт станции перенаправляет https → http, браузер блокирует (CSP). Безвредно: показывается буква станции.

## Грабли, которые уже случались
- Bash-heredoc ломает `${...}` и `\b` в регулярках и в шаблонных строках. Для правок с кавычками пиши Python-скрипт через инструмент записи файла (Write), а не через heredoc в shell.
- В Python внутри строк `"""..."""` не удваивай слеши случайно: `\n` и `\s` превращаются в реальные символы.
- Каждая строка `tx('…')` с русским текстом должна иметь ключ в `lib/i18n.en.ts`. Иначе английская версия показывает русский текст. Не дублируй ключи в объекте (TypeScript падает).
- Скриншоты превью иногда не снимаются (таймаут). Для снимков используй Playwright со скриптом в scratchpad.
- Ключи в `lib/i18n.en.ts` и `tx()` сверяй при каждом изменении текста.
- Тесты отдельные: модульные — `tests/*.test.ts` (окружение node, без React), браузерные — `tests/e2e`.
