Скопируй этот текст целиком в новую сессию агента. Актуально на версию **1.8.14** (опубликована).

Ты продолжаешь разработку **Heddify** — Windows-приложения (Electron) для прослушивания музыки из SoundCloud, Яндекс Музыки и Audius, а также радио, собственных файлов и «Моей волны». Репозиторий: `C:\Users\Heddrate\Desktop\1337\sc-player`, GitHub `Heddrate/Heddify`, ветка `main`.

## Владелец и стиль работы
- Владелец — **Heddrate**. Пишет по-русски, неформально. Отвечай коротко и по-русски. Без воды и без пересказа того, что он и так видит.
- Он хочет, чтобы всё делалось **само, «под ключ»**: код, тесты, релиз. Спрашивай только то, что требует его решения: деньги, аккаунт, выбор функции, риск для пользователей.
- Если нужны его шаги — давай 1–3 простых, без жаргона.
- Просьбы вида «выпускай», «давай», «деплой» — это релиз. Без такой просьбы не коммить и не пушь.
- «Задеплоил?» значит: собран ли и опубликован ли релиз. Проверяй через API GitHub, не угадывай.
- Он часто присылает скриншоты с критикой («кривое», «криво», «ужас»). Смотри на скрин, найди конкретную причину и поправь именно её, а не переделывай всё подряд.
- Он хочет «идеально» и просит проверять каждый раз всё. После каждой правки: типы, тесты, браузерные тесты, сборка.

## Что нельзя (жёстко)
- **Не запускать Electron** с приложением (ни установленное, ни тестовое). Владелец дважды отклонил запуск из инструмента. Визуальные проверки — только в браузерном превью (`npm run dev:web`) через Playwright.
- **Не трогать установленную у владельца версию** (`C:\Program Files\SC Player\Heddify.exe`, MSIX-виртуализация AppData).
- **Не обходить DRM**: не трогать протокол лицензий SoundCloud, не запускать castlabs EVS-подпись, не разбирать ответы лицензионного сервера. Сборку castlabs с Widevine и VMP-подписью уже пробовали: сервер лицензий SoundCloud отвечает 403. Это решено, не переоткрывать. Вместо этого DRM-трек SoundCloud играет из Яндекс Музыки, если там есть та же запись (`lib/twin.ts`: название, артист, версия, длительность ±4 с; `store/player.ts`, `standIns`). Не нашлось — кнопка «открыть в браузере».
- Не решать капчи и антибот, не вытаскивать client_id из JS SoundCloud, не подписывать запросы и не получать stream-URL Яндекса в обход официальной страницы music.yandex.ru.
- Не извлекать, не читать и не печатать токены, пароли и cookie пользователя.
- **Не покупать ничего** (сертификаты, подписки) без его «да».
- В коммитах и PR **не добавлять** `Co-Authored-By: Claude…` и «Generated with Claude Code». Автор коммита: `Heddrate <211876846+Heddrate@users.noreply.github.com>`. Это его собственный проект.
- Не переписывать уже опубликованную историю и теги. Если сборка упала — чинить и выпускать следующую версию.

## Репозиторий и структура
- **Стек:** Electron (electron-vite), React 19, zustand 5, TypeScript, hls.js, vitest, Playwright.
- **Версия:** `package.json`, строка 4 (`"version"`). `package-lock.json` версию не поднимаем — так было всегда.
- **Главный процесс `src/main/`:** `index.ts` (окно без системной рамки `frame: false`, IPC, кнопки окна `window:control`, трей, миниатюра в панели задач), `soundcloud.ts`, `auth.ts`, `updater.ts` (электрон-апдейтер, проверка при старте через 15 с и каждые 4 ч, скачивание в фоне), `local.ts` (свои файлы, протокол `heddify-local://`), `tray.ts`, `discord.ts`, `userData.ts`, `mediaKeys.ts`, `thumbIcons.ts`.
- **`src/preload/`:** `index.ts` (мост `window.sc`), `yandex.ts` (скрытая страница Яндекса: громкость через Web Audio gain, запрет самостоятельного старта звука `__scAllowPlay`, анализатор выхода `__scBass` для подсветки баса и данных для плавного перехода), `login.ts`.
- **`src/shared/ipc.ts`:** типы моста `ScBridge` (включая `win` для кнопок окна).
- **`src/renderer/src/`:**
  - `store/player.ts` — очередь и воспроизведение; `lib/queueOrder.ts` — чистая логика порядка (перемешивание через `plan`, история через `history`, следующий трек, «что дальше»). Покрыто тестами.
  - `player/engine.ts` — `<audio>`, HLS, выравнивание громкости, плавный переход, подсветка баса (анализатор 4096 точек, полоса 25–200 Гц). `player/audioMath.ts` — `fadeGain`.
  - `lib/bass.ts` — чистые функции баса: `stepBass`, `bassBinRange`, `bassDb`, константы полосы.
  - `lib/yandex.ts` — драйвер Яндекса (опрос страницы 20 раз в секунду, уровень баса для полного экрана, громкость страницы с плавным переходом).
  - `lib/api.ts` (SoundCloud API), `lib/radio.ts` (Radio Browser, https, логотипы через `secure()`), `lib/local.ts`, `lib/artists.ts` (имена артистов трека, соавторы из title/publisher_metadata), `lib/actions.ts` (`openArtistRef`), `lib/update.ts`, `lib/i18n.ts` + `lib/i18n.en.ts` (переводы).

  - `views/` — `Home.tsx` (баннер `Hero` и полки), `Settings.tsx` (карточки-разделы; две колонки по ширине страницы через container query), `Radio.tsx`, `Playlist.tsx`, `Wave.tsx` (Моя волна), `Search.tsx`, `Library.tsx`, `Files.tsx`, `Login.tsx`, `Local.tsx`, `Yandex.tsx`, `User.tsx`, `Audius.tsx`.
  - `styles/` — `themes.css` (цвета тем и палитр), `base.css`, `layout.css` (сетка приложения, шапка, `--tb-right: 200px`), `components.css`, `views.css`, `motion.css`, **`shell.css`** (сплошные панели, рейл, шапка страниц, баннер, поиск, кнопки окна; грузится последним).

## Как выпустить версию
1. Новая версия — следующая после последнего тега (сейчас последний `v1.8.14`, значит `1.8.15`). Проверь `git tag --list` и `git fetch`, прежде чем поднимать номер.
2. Поднять `version` в `package.json` (строка 4).
3. Написать `release/notes/vX.Y.Z.md` — короткие пункты по-русски, что изменилось **для пользователя**. Простым языком, как человек пишет другу: без двоеточий-пояснений, без технических слов (DRM, CORS, кэш, схемы), без внутренних исправлений. Владелец просил: «менее нейронный текст». Эти строки видны в «Что нового».
4. `git add -A`, коммит без Co-Authored-By, `git push origin main`.
5. `git tag vX.Y.Z` и `git push origin vX.Y.Z` — это запускает сборку.
6. Проверка: `curl https://api.github.com/repos/Heddrate/Heddify/actions/runs?per_page=1` (status, conclusion) и `…/releases/latest`. Один-два запроса, без поллинга в цикле.
7. Перед коммитом проверь `git status`: не должно быть лишних tmp-файлов в репозитории (скрипты и скриншоты — в scratchpad, не в проекте).

- **DRM-треки SoundCloud** не играют (тупик, см. выше). **Spotify** не поддерживается.
- **Картинка радио по http:** сайт перенаправляет https на http, браузер блокирует. Безвредно: показывается буква станции.

## Грабли, которые уже случались
- **Web Audio и свои схемы.** Пока включены подсветка баса или выравнивание громкости, `<audio>` идёт через Web Audio. Файл со своей схемы (`scp-cache://`, `heddify-local://`) для страницы — чужой источник, и Web Audio отдаёт вместо него тишину, а Chromium пишет об этом только как info (теперь это попадает в api.log: `outputs zeroes`). Поэтому кэш и свои файлы в этом режиме играют из памяти через blob (`engine.own`). Не убирать.
- **Настоящий лог приложения** из инструментов Claude читается через `//localhost/C$/Users/Heddrate/AppData/Roaming/SC Player/logs/api.log`: обычный путь показывает старую копию из виртуализации MSIX.
- **Bash-heredoc** ломает `${…}`, обратные кавычки, `\b`, `\n` в строках. Для правок с кавычками пиши Python-скрипт через инструмент записи файла (Write), потом запускай его. Регулярки и шаблонные строки особенно чувствительны.
- **Python-строки `"""…"""`:** `\n` и `\s` превращаются в настоящие символы, если не удвоены. Проверяй результат через `grep`.
- **Два агента в одном репозитории.** Однажды появились чужие коммиты 1.8.5–1.8.8, мой коммит ушёл поверх и был назван не тем номером. Перед коммитом: `git fetch`, `git status`, `git log origin/main`. Если есть чужие коммиты — не перезаписывать, выпускать свою следующую версию и предупредить владельца.
- **Переводы:** каждая новая `tx('…')` сразу в `lib/i18n.en.ts`. Иначе английская версия показывает русский текст.
- **Тесты на порядок очереди** — по `id` треков, а не по позициям (`unplayable` хранит id).
- **Container queries** по ширине страницы (`.main`) и по `.app` — не по ширине окна.
- **Скриншоты превью иногда не снимаются** (таймаут). Тогда Playwright со скриптом в scratchpad.
- **Скрипт проверки переводов** (`scratchpad/i18ncheck.js`) лежит в scratchpad предыдущей сессии, в новой его может не быть. Тогда проверь вручную: все `tx('…')` с кириллицей есть в `lib/i18n.en.ts`.

## Как работать
1. Прочитай задачу. Если она неясна — один вопрос, не список вопросов.
2. Найди место в коде поиском, не угадывай.
3. Измени; если логика чистая — добавь тест (`lib/queueOrder`, `lib/bass`, `lib/artists`, `player/audioMath`).
4. Проверь типы, `npm test`, `npm run test:e2e`, `npm run build`. Визуально — в превью с нужной темой и эмуляцией прозрачности (см. выше).
5. Если просили выпуск — версия, заметки по-русски, коммит без Co-Authored-By, тег, проверка сборки через API.
6. Ответ владельцу: что сделано, что проверено, и что **не** проверено (живое окно, звук, аккаунты) — честно.
